# Mendi Secondary School Website

This project is part of **IS229 – Web Design Assessment 2**. It is a complete multi-page website representing Mendi Secondary School for students, parents and the local community.

The website uses meaningful semantic structure, accessibility features and realistic user tasks such as learning about the school, exploring programmes, reading school information and contacting staff.

## Website Structure

The site contains five HTML pages:

- **Home (`index.html`)** – Introduction, motto and school highlights.
- **About (`about.html`)** – History, vision, mission, motto and values.
- **Programmes (`programmes.html`)** – Subjects and academic programme information.
- **Information (`information.html`)** – News, events and multimedia gallery.
- **Contact (`contact.html`)** – Contact details, live map and enquiry form.

Every page includes consistent navigation, semantic HTML5 elements (`header`, `nav`, `main`, `section`, `article` and `footer`) and a logical heading hierarchy.

## Technologies Used

- HTML5 for semantic structure and content
- CSS3 for layout, readability and responsive styling
- Visual Studio Code as the text editor
- Git and GitHub for version control
- GitHub Pages for publication

No templates, frameworks or site builders were used.

## Features

- Metadata descriptions for SEO and accessibility
- Consistent navigation across all pages
- Responsive external stylesheet
- Contact form with labels, correct input types and required-field validation
- Live Google Map on the Contact page
- Accessible image gallery with descriptive alternative text
- Progressive Git history showing development
