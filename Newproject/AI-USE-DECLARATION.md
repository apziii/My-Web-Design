# AI Use Declaration

This project was developed by Anthon as part of **IS229 – Web Design Assessment 2** at PNGUoT.

During the development process, I used Microsoft Copilot (AI assistant) to support my work. The AI was used in the following ways:

- To help plan the overall structure of the website (Home, About, Programmes, Information and Contact).
- To provide written explanations of page content and assignment requirements.
- To draft sample HTML and CSS code blocks for the Home page and other sections.
- To generate a `README.md` template and AI Use Declaration text.

All code and content were reviewed, edited and finalized by me before submission.

The AI did not publish the site, manage GitHub commits or validate the HTML; those tasks were completed manually.

I confirm that the use of AI was declared honestly and transparently, and that the final work represents my own effort and understanding of web design principles.
